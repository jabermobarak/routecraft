# RouteCraft

Локальная классификация запросов: десять намерений и отправка неуверенных ответов на проверку. Реальное дообучение LoRA, а не имитация вызова модели.

**Стек:** Python, PyTorch, Transformers, PEFT/LoRA, scikit-learn, FastAPI, Docker, pytest, GitHub Actions.

На 300 отложенных запросах точность LoRA — **97,3%**, замороженного энкодера — 91,7%, TF-IDF — **98,7%**. На 1 000 запросах вне области задачи LoRA ошибочно принимает 6,6%, TF-IDF — 14,5%. Пороги выбраны отдельно на валидации; это сравнение рабочих точек, а не одинакового покрытия.

Обучаются 9 482 параметра (0,216% модели). Веса базового энкодера остаются неизменными. Данные — реальная публичная выборка CLINC150. Разделы для выбора эпохи, калибровки, выбора порога и финального теста разделены.

## Запуск

Нужен Python 3.11 или 3.12. Из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[dev]'
python -m routecraft.cli serve
```

Откройте http://127.0.0.1:8030. Веса включены в репозиторий, API-ключ не нужен. Альтернатива — `docker compose up --build`.

Это англоязычный энкодер для классификации, а не генеративная LLM. Приложение предлагает маршрут, но не выполняет действия. Проверка запросов вне задачи несовершенна.

Подробности, воспроизведение, лицензии и ограничения — в [README](README.md) и [карточке модели](docs/model-card.md).
